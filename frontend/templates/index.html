PCAP Analysis

OFFLINE Analysis Workflow

Uploading a PCAP here does not automatically run Suricata. This is an offline workflow:
1. Capture traffic with Wireshark on your network → export as .pcap or .pcapng
2. Upload the file here for storage and record-keeping
3. Separately, run: suricata -r your_capture.pcap -c /etc/suricata/suricata.yaml -l /var/log/suricata/
4. Copy the resulting eve.json to the configured path, set DATA_MODE=suricata, and restart the dashboard
